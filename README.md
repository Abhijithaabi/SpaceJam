# Laser Defender

A 2D top-down space shooter game created with Unity.

## How to Play

### Controls

-   **Keyboard**:
    -   Move: `WASD` or `Arrow Keys`
    -   Shoot: `Space`
-   **Mouse**:
    -   Shoot: `Left Mouse Button`
-   **Gamepad**:
    -   Move: `Left Stick`
    -   Shoot: `Right Trigger`
-   **Touchscreen**:
    -   Move: Drag the ship
    -   Shoot: Tap the screen

## Features

-   **Enemy Waves**: Fight against waves of enemies with different attack patterns.
-   **Scoring System**: The game keeps track of your score.
-   **Multiple Enemy Types**: Encounter different types of aliens with unique behaviors.
-   **Power-ups**: Collect power-ups to enhance your ship's abilities.
-   **Boss Battles**: Face challenging boss battles at the end of waves.

## Installation

To open and run this project, you will need to have Unity Hub and Unity Editor version `2021.3.0f1` installed.

1.  Clone the repository to your local machine.
2.  Open Unity Hub.
3.  Click on "Add" and select the cloned project folder.
4.  The project will now be available in your Unity Hub projects list. Click on it to open it in the Unity Editor.
